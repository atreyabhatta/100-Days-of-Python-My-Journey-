# Day 4 — My First Python Program

## Writing my first program from scratch

Today was about actually writing my very first Python program — nothing
fancy, just a bunch of `print()` statements, but it felt like a good
milestone. `print()` is the simplest way to display something on the
console, and it's usually the first thing anyone learns in any language.

Sometimes the "Hello World" moment matters more than the complexity of the
code itself — this was mine for Python.

## Quick Quiz — Print a poem

The task for today was to write a short program that prints a poem of my
choice, just using multiple `print()` statements.

```python
print("---my poem here---")
```

Simple exercise, but it's a good way to practice basic syntax, string
formatting, and get comfortable with running a Python file end-to-end
before moving into more complex topics.

## My takeaway

Nothing complicated today, but every big project starts with small steps
like this. Getting comfortable with `print()` and running programs
end-to-end is the foundation everything else in this course will build on.
