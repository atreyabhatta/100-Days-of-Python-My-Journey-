# Day 2 — What Can Python Do for Me?

## My Python Learning Journey

Welcome to Day 2 of my 100 Days of Code journey!

Today, while going through CodeWithHarry's Python course, I came across his
story about how Python became an important part of his career. It made me
think about my own journey with programming.

My background is quite different — I am a BSc Physics graduate, and I did not
come from a computer science or programming background. During my academic
years, my main focus was Physics, so I did not have strong experience with
programming when I started thinking about moving into Data Science.

I actually started learning programming in 2024, while preparing myself for
an MSc in Data Science abroad. Since I did not have a strong coding
background, I realised that learning programming was going to be an
important part of building the foundation I needed for Data Science.

At the beginning, programming felt quite different from what I was used to
in Physics. I had to learn how to think logically, understand syntax, write
programs, debug errors, and gradually break bigger problems into smaller
steps.

I started exploring Python because of its importance in Data Science,
Machine Learning, automation, and many other areas of technology.

Now, in 2026, I am revisiting and documenting my Python learning journey
through the 100 Days of Code challenge. I am not simply learning Python for
the sake of completing a course — my goal is to build a proper programming
foundation that I can use throughout my Data Science journey.

## What Can Python Do for Me?

One of the things I learned from today's lesson is that Python is much more
than just a programming language for writing simple programs.

As I progress, I want to understand how Python can be used for:

- Data analysis
- Data cleaning and manipulation
- Automation
- Web scraping
- Data visualization
- Machine Learning
- Artificial Intelligence
- Building applications
- Working with APIs
- Solving real-world problems

I have already started exploring some of these areas through today's 5 mini
projects (Jarvis Virtual Assistant, Love Calculator, Face Recognition,
Flappy Bird Game, and Snake Game), but I know there is still a lot to learn.

For now, I am focusing on building the fundamentals step by step rather than
trying to learn everything at once.

This is only Day 2 of 100 Days of Code, but I am hoping that by the end of
these 100 days, I will be much more confident in Python and, more
importantly, better prepared for my journey into Data Science.

**From Physics to Python to Data Science — one day at a time.**
